# Changelog

## 1.0.0 — initial release

- Multi-plan startup management with file drop, installed desktop/Store discovery, grouping, search, batch actions and reordering.
- Real Windows launch services for applications, AUMIDs, URLs, shell files, folders, shortcuts, scripts and commands.
- Sequential delays, shared timeline, independent retries, execution snapshots, serial plan queue and cancellation.
- Per-user sign-in entry, explicit plan choice, single instance, tray and one-shot next-logon skip.
- Local atomic JSON storage, backup recovery, reviewed merge/replace import and editable export.
- Simplified Chinese / English, system/light/dark appearance, self-contained x64 packages and beginner documentation.

See 验证报告.md for the distinction between code tests, actual Windows checks and remaining manual scenarios. This version is unsigned. GitHub publication does not imply that every platform scenario has been certified.
